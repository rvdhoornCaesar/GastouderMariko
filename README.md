# Gastouder Uren

Eenvoudige tool waarmee gastouder Mariko online haar uren kan invullen.

- Meerdere kinderen, elk met één of meer contracten (eigen uurtarief).
- Meerdere registraties per dag (kind/contract, van–tot, pauze, opmerking).
- Maandoverzicht met uren en bedrag per kind/contract, CSV-export en afdrukken.
- Back-up/herstel als JSON.

## Gebruik

Open `index.html` in een browser, of host het als statische site (bijv. GitHub Pages).
Er is geen server nodig: gegevens worden opgeslagen in de browser (`localStorage`) van het apparaat dat ze invult.
Maak daarom regelmatig een back-up via de tab *Kinderen*.
